- A cached bullet is reused only when the run's output is that exact file and the file still has the recorded content.
- A run aimed at a different output file no longer reads or rewrites the shared cache; it warns and names the file the cache belongs to.

## 2. Add `CacheStatus` and extend the `Cache` interface

Add the status type and the new methods to the interface. The full interface must be:

```go
//counterfeiter:generate -o ../../mocks/distill-cache.go --fake-name DistillCache . Cache

// CacheStatus classifies how a loaded cache relates to the output file of the
// current run.
type CacheStatus int

const (
	// CacheCold means there is nothing to serve: the cache file is missing or
	// corrupt, or the output file needed for a rebuild is missing.
	CacheCold CacheStatus = iota
	// CacheWarm means the cache is bound to this run's output and its recorded
	// content hash matches the file on disk.
	CacheWarm
	// CacheRebuild means the cache exists but is unbound or its recorded output
	// hash is stale; entries must be rebuilt from the output file.
	CacheRebuild
	// CacheForeign means the cache belongs to a different output path.
	CacheForeign
)

// Cache stores validated bullets keyed by rule id, guarded by a content hash so
// a changed rule (or changed compression context) is a miss.
type Cache interface {
	// Get returns the cached bullet for id when the stored hash equals hash.
	Get(id, hash string) (bullet string, ok bool)
	// GetPrevious returns the last validated bullet for id regardless of its
	// content hash, so a changed rule can be revised from its prior rendering
	// instead of re-derived from scratch.
	GetPrevious(id string) (bullet string, ok bool)
	// Put records a validated bullet for id under hash (pending write).
	Put(id, hash, bullet string)
	// Load reads the cache from disk and classifies it against outputPath,
	// which must be the normalized absolute form of the run's --output.
	Load(ctx context.Context, outputPath string) error
	// Status reports the classification produced by the last Load.
	Status() CacheStatus
	// Save persists the cache pruned to keepIDs and binds it to outputPath and
	// the SHA-256 of the bytes currently at outputPath.
	Save(ctx context.Context, outputPath string, keepIDs []string) error
	// SaveMerged persists all entries without pruning and without changing the
	// binding recorded by Load.
	SaveMerged(ctx context.Context) error
	// RuleHash derives the content hash for a rule body under the current
	// compression context (prompt-version constant + system.md + model + body).
	RuleHash(model, body string) string
}
```

## 3. Add the path and hash helpers

In `pkg/distill/cache.go`, add:

```go
// normalizeOutputPath returns the absolute, cleaned form of path. Symlinks are
// not resolved, so two spellings of the same path share one binding.
func normalizeOutputPath(ctx context.Context, path string) (string, error) {
	abs, err := filepath.Abs(path)
	if err != nil {
		return "", errors.Wrapf(ctx, err, "resolve absolute output path %q", path)
	}
	return filepath.Clean(abs), nil
}

// hashOutput returns the hex SHA-256 of content.
func hashOutput(content []byte) string {
	sum := sha256.Sum256(content)
	return hex.EncodeToString(sum[:])
}
```

`filepath.Abs` must be followed by `filepath.Clean`. Do **not** use `filepath.EvalSymlinks` (the spec requires symlinks unresolved).

## 4. Extend `fileCache` and implement the classification in `Load`

Add two fields to `fileCache`:

```go
type fileCache struct {
	path    string
	warn    io.Writer
	loaded  map[string]cacheEntry
	pending map[string]cacheEntry
	status  CacheStatus
	binding cacheBinding
}

// cacheBinding is the output binding recorded by Load and reused by SaveMerged.
type cacheBinding struct {
	OutputPath string
	OutputHash string
}
```

`Load(ctx, outputPath)` must reset `loaded` and `pending` to non-nil empty maps (so a later `Put` cannot panic on a nil map), reset `status` to `CacheCold`, and reset `binding` to its zero value, then classify the file. It never returns a non-nil error; every failure is a warning plus a cold/rebuild/foreign status. The classification rules are:

1. **Cache file unreadable.** `os.ReadFile(c.path)` fails:
   - `os.IsNotExist` → write `distill: cache file %q missing — running cold\n` (keep the existing wording), status `CacheCold`.
   - any other error → write `distill: cache file %q unreadable — running cold\n`, status `CacheCold`.
   - Return nil. Leave `loaded` empty.
2. **Cache file corrupt.** `json.Unmarshal` fails → write `distill: cache file %q corrupt — ignoring, running cold\n` (keep the existing wording), status `CacheCold`, return nil. Leave `loaded` empty.
3. **Schema version mismatch.** `cf.Version != cachePromptVersion`:
   - If `os.Stat(outputPath)` succeeds → write `distill: cache schema version mismatch — rebuilding from output\n`, status `CacheRebuild`.
   - Otherwise → write `distill: cache schema version mismatch — running cold\n`, status `CacheCold`.
   - Return nil. Leave `loaded` empty.
4. **Unbound cache.** `cf.OutputPath == "" || cf.OutputHash == ""`:
   - If `os.Stat(outputPath)` succeeds → write `distill: cache has no output binding — rebuilding from output\n`, status `CacheRebuild`.
   - Otherwise → write `distill: cache has no output binding — running cold\n`, status `CacheCold`.
   - Return nil. Leave `loaded` empty.
5. **Bound cache.** Set `c.binding = cacheBinding{OutputPath: cf.OutputPath, OutputHash: cf.OutputHash}`.
   - If `cf.OutputPath != outputPath` → write `distill: cache file %q belongs to output %q, not %q — run against that output or delete the cache file\n` (the warning MUST name the recorded output and the remedy), status `CacheForeign`, return nil. Leave `loaded` empty: a foreign run reads no entries.
   - Read the output file. If the read fails → write `distill: output file %q missing — running cold\n`, status `CacheCold`, return nil. Leave `loaded` empty.
   - If `hashOutput(data) != cf.OutputHash` → write `distill: cache output hash mismatch for %q — rebuilding from output\n`, status `CacheRebuild`, return nil. Leave `loaded` empty: the rebuild must read the file, never the stale entries.
   - Otherwise → status `CacheWarm`, and set `c.loaded = cf.Entries` (if nil, use an empty map).

For `CacheCold`, `CacheRebuild`, and `CacheForeign`, `loaded` MUST remain empty so `Get` cannot serve stale entries. This is load-bearing for the fallback-to-cold behavior.

Add a `Status()` method returning `c.status`. Add an `outputPath` read with a `#nosec G304` comment naming the `--output` argument as the source (mirror the existing `#nosec` comment on the cache-path read).

Split the classification into small helpers (for example `reset`, `warnCold`, `classify`, `classifyUnbound`) so `Load` and each helper stay under the `funlen` limit (80 lines / 50 statements), `nestif` stays below 4, `gocognit` stays below 20, and `maintidx` stays at least 20.

## 6. `SaveMerged` preserves the binding

`SaveMerged(ctx)` must persist the union of `loaded` and `pending` with **no pruning**, using the binding captured by `Load`:

```go
return c.persist(ctx, cacheFile{
	Version:    cachePromptVersion,
	OutputPath: c.binding.OutputPath,
	OutputHash: c.binding.OutputHash,
	Entries:    entries,
})
```

Do not read the output file and do not rebind. When `Load` recorded no binding (missing, corrupt, or version-mismatched cache), the merged save writes an unbound cache (the `omitempty` fields are absent); do not invent a binding on a failed run.

8c. Replace the inline save calls with helpers that skip foreign outputs and `--no-cache`:

```go
// saveUnlessForeign persists the cache after a successful run. A foreign output
// is never written; --no-cache never writes.
func (d *Driver) saveUnlessForeign(
	ctx context.Context,
	status CacheStatus,
	outputPath string,
	enabled []Rule,
) {
	if d.NoCache || status == CacheForeign {
		return
	}
	if saveErr := d.Cache.Save(ctx, outputPath, ruleIDs(enabled)); saveErr != nil {
		fmt.Fprintf(d.Stderr, "distill: cache save warning: %v\n", saveErr)
	}
}

// saveMergedUnlessForeign merges validated bullets after a failed run. A foreign
// output is never written; --no-cache never writes.
func (d *Driver) saveMergedUnlessForeign(ctx context.Context, status CacheStatus) {
	if d.NoCache || status == CacheForeign {
		return
	}
	if saveErr := d.Cache.SaveMerged(ctx); saveErr != nil {
		fmt.Fprintf(d.Stderr, "distill: cache save warning: %v\n", saveErr)
	}
}

// ruleIDs returns the ids of rules in order.
func ruleIDs(rules []Rule) []string {
	ids := make([]string, 0, len(rules))
	for _, r := range rules {
		ids = append(ids, r.ID)
	}
	return ids
}
```

On the compile-failure path call `d.saveMergedUnlessForeign(ctx, status)`; on the success path call `d.saveUnlessForeign(ctx, status, normalizedOutput, enabled)`.
